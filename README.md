# Swan Defence Dedicated Terminal (Custom Days: 1, 2, 5, 14, 28 Days Added)

### What's New:
1. **Custom Day Filters Added**:
   - **1D**: Today's complete intraday sessions (09:15 - 15:30 IST) with High ₹2,870, Low ₹2,776, and Close ₹2,828.00.
   - **2D**: Yesterday + Today intraday sessions.
   - **5D**: 5 Trading Days (1 full trading week).
   - **14D**: 14 Trading Days (2 weeks, default view).
   - **28D**: 28 Trading Days (~1 full trading month).
   - Plus **3M**, **1Y**, and **ALL** for macro trends.
2. **Dynamic Candle Width**: 1D, 2D, and 5D have wider candle spacing (`barSpacing: 16`) so individual sessions and wicks look crisp and bold on mobile!
3. **Responsive Scroll Bar**: Timeframe buttons sit in a smooth horizontal scrolling bar.
