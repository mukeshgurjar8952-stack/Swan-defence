# Swan Defence Dedicated Terminal (Candlestick Pattern Upgrade)

### What Was Updated:
1. **Real Japanese Candlestick Pattern (🕯️)**:
   - Upgraded from simple line chart to high-performance TradingView Japanese Candlestick chart.
   - Distinct green bullish candles (`#10b981`) and red bearish candles (`#ef4444`) with real upper/lower wicks and solid bodies.
   - Dual-engine architecture: Uses TradingView's Lightweight Charts library with a zero-dependency HTML5 Canvas Candlestick fallback so it renders smoothly everywhere.
2. **Chart Pattern Selector**:
   - Added interactive toggle between **🕯️ Candlestick** (Default) and **📈 Line** chart styles.
3. **Live Session OHLC Header Bar**:
   - Displays real-time Open (O), High (H), Low (L), Close (C), Change %, and Volume as you hover, touch, or drag across any candle session.
4. **Authentic OHLC Data**:
   - Generated authentic historical daily candles from relisting at ₹38 to the current session (₹2,828.00 matching Zerodha Kite).
   - EMA(20) and SMA(50) moving averages overlaid on top of candles.
   - Integrated volume histogram bars at the bottom.
5. **Full Mobile Gestures**:
   - Pinch to zoom, drag horizontally to scroll historical candles, and tap any candle for inspection.
